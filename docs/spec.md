# Spec: HanKey — 한영 전환 키를 바꾸는 메뉴바 앱

- 작성일: 2026-11-13
- 대상: 새 프로젝트 `hankey/` (Swift 6.4 · AppKit · SwiftPM, macOS 13+, 개발 환경 macOS 27.0 arm64)
- 배경: Caps Lock 한영 전환은 macOS 가 Caps Lock 입력에 거는 오타 방지 지연 때문에 빠르게 치면 누락된다. 지연은 HID 드라이버 단계에서 생기므로 앱 단계 이벤트 가로채기로는 못 없앤다.

## 1. 동작 방식 (결정됨)

1. **키 바꾸기 — HID 단계.** 사용자가 고른 키를 `hidutil` 의 `UserKeyMapping` 으로 **F18** 로 바꾼다. 권한 요청이 없고 지연도 없다.
2. **전환 — 시스템에 맡긴다.** 시스템 단축키 "이전 입력 소스 선택"(`com.apple.symbolichotkeys` 60번)을 F18 로 바꾼다. 앱이 입력 소스를 직접 바꾸는 방식(`TISSelectInputSource`)은 한글 입력기로 넘어갈 때 표시만 바뀌고 입력은 안 바뀌는 문제가 알려져 있어 쓰지 않는다.
3. **언어는 Swift.** 메뉴바 · 로그인 항목 · 환경설정 API 가 모두 AppKit 쪽이고, 이 맥에 Rust 도구가 없다.

### 1-1. 즉시 전환 (11/13 추가)

- 실측: 시스템 단축키는 키를 **뗄 때** 전환한다(F18 을 0.4초 누르면 뗀 뒤 약 40ms 에 바뀜). 전환 키를 떼기 전에 다음 글자를 치면 이전 언어로 찍힌다.
- 손쉬운 사용 권한이 있으면: 고른 키를 **F19** 로 바꾸고, 앱이 F19 누름(전역 단축키, 키 반복에는 불리지 않음)을 받아 F18 누름 · 뗌을 바로 이어 보낸다. 실제 키를 오래 눌러도 누른 직후 전환된다.
- 권한이 없으면 기본 방식(F18 직접 매핑, 뗄 때 전환)으로 동작한다. 메뉴의 "누르는 즉시 전환 켜기…"로 권한을 요청하고, 허용되면 자동으로 바뀐다.
- 80ms 안의 연속 누름은 한 번으로 본다(접점 떨림).

## 2. 메뉴 구성

| 항목 | 동작 |
|---|---|
| 상태 줄 | "동작 중 — {키} · 누르는 즉시 전환 / 키를 뗄 때 전환" / "키를 선택하세요" / "시스템 단축키 연결 안 됨" |
| 누르는 즉시 전환 켜기… | 권한이 없을 때만 보인다. 손쉬운 사용 권한 요청 |
| 전환 키 (하나만 선택) | Caps Lock · 오른쪽 Command · 오른쪽 Option · 오른쪽 Shift · 오른쪽 Control · 사용 안 함 |
| 다시 연결 · 키보드 설정 열기 | 연결이 안 됐을 때만 보인다 |
| 로그인 시 실행 | `SMAppService.mainApp` 등록 · 해제 |
| 종료 | 키 매핑과 시스템 단축키를 원래대로 돌리고 끝낸다 |

## 3. 규칙

- 처음 실행은 "사용 안 함". 사용자가 키를 고르기 전에는 시스템 설정을 건드리지 않는다.
- 키 선택 시: 매핑 적용 → 60번 단축키의 지금 값을 백업 → F18 로 바꿈 → `activateSettings -u` 로 반영 → WindowServer 의 실제 값(`CGSGetSymbolicHotKeyValue`)으로 연결 여부 확인.
- "사용 안 함" · 종료 시: 우리 매핑(F18 · F19 로 가는 항목)만 지우고, 백업이 있고 지금 값이 F18 일 때만 단축키를 백업 값으로 되돌린다. 사용자가 그사이 직접 바꾼 값은 덮어쓰지 않는다.
- 매핑은 재부팅하면 풀리므로 실행 시 · 잠자기 해제 시 · 메뉴를 열 때 다시 적용한다.
- 다른 `UserKeyMapping` 항목은 읽을 수 있으면 보존한다(같은 키에서 출발하는 항목은 교체).
- Caps Lock 을 고를 때 Caps Lock 이 켜져 있으면 막고 안내한다(켜진 채로 바꾸면 끌 수 없게 된다).
- 고른 키의 원래 기능은 앱이 켜져 있는 동안 사라진다.

## 4. 구조

- `HanKeyCore` (순수 로직, 테스트 대상): 키 목록과 HID 코드, 매핑 병합, `hidutil` JSON, 단축키 값 판별 · 연결 · 복원 계산.
- `HanKey` (앱): 메뉴, `hidutil` 실행, 환경설정 읽기 · 쓰기, 로그인 항목.
- `scripts/build-app.sh`: 릴리스 빌드 → `dist/HanKey.app` (LSUIElement, ad-hoc 서명).

## 5. 테스트

- 단위: 매핑 병합(추가 · 교체 · 보존 · 해제), JSON 값, 단축키 판별(F18 · Ctrl+Space · 꺼짐 · 보조 키 조합), 연결 · 복원 계산(백업 유무, 사용자가 바꾼 경우).
- 실기: 사용자가 키를 골라 빠르게 눌러 전환 누락이 없는지 확인. 자동 테스트는 실제 키보드 설정을 바꾸지 않는다.

## 6. 범위 밖

- 키 조합(예: Shift+Space), 입력 소스 3개 이상일 때의 전환 순서 지정.
- 메뉴바에 현재 입력 언어 표시.
- 배포용 서명 · 공증.
